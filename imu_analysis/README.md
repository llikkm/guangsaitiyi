# LSM6DS3TR-C 六轴实测标定

在仓库根目录运行 `python imu_analysis/calibrate.py --out imu_analysis/results.json`。脚本需要 NumPy，传感器运行时仅使用 Python 标准库。原始 CSV 从本机 `imu_data/` 读取，结果文件只保存统计值。脚本也会核对仿真默认参数与重新拟合的结果。

## 采集和分组

记录的寄存器设置为 104 Hz、加速度计 ±2 g、陀螺仪 ±250 °/s，换算步长分别为 0.000061 g/count 和 0.00875 °/s/count。软件滤波关闭。十分钟静置记录的实际平均采样率为 104.021 Hz。脚本逐个检查时间戳单调性和序号连续性，积分使用每两个样本的实际时间差。

用 `static10` 求静止零偏和波动，用六个 `face_*` 求加速度计的零偏和增益，用 `cw1/2`、`ccw1/2` 估计绕 Z 转动的增益。各次采集统一舍弃前 2 秒，因为启动时陀螺仪出现过明显的瞬态。验证单独使用 `static2`、`cw3`、`ccw3`。其中 `static2/settings.json` 标成 development，本次按采集名称预留。试采和文件名为 `samples.partial.csv` 的中断采集均跳过。

取静置台面为水平面，扣除加速度计零偏和增益，根据重力方向估算等效滚转角 +0.618°、俯仰角 −1.187°。重力数据无法给出水平安装朝向，默认偏航安装角取 0°。手转的实际角度和台面倾斜都会影响这些估值。装车后可用 `mount_rpy_deg` 替换三个角。

**仿真假设**包含传感器位于车体中心、三轴相互独立、单样本噪声服从高斯分布。随机游走每轴取 0.0002 (°/s)/√s 和 0.000005 g/√s，每步增量乘以实际时间差的平方根。读取延迟设为 5 ms。日志只有采样时刻，无法求出从采样到控制器收到数据的延迟。Stress 将噪声标准差、随机游走增量标准差和延迟都乘以 3。104 Hz 的单点波动沿用到其他可选采样率时属于近似。

## 独立验证

对两次手转验证记录逐轴扣除开发集零偏、除以增益，再投影到车体竖直轴并做梯形积分。约定从上往下看，逆时针为正。

| 留出记录 | 参考 | 标定后的积分 | 差值 |
|---|---:|---:|---:|
| cw3 | −360° | −359.53° | +0.47° |
| ccw3 | +360° | +353.57° | −6.43° |
| static2 有效 118 s | 0° | +2.21° | +2.21° |

固定随机种子 20261128，让静止虚拟车使用 `static2` 的采样间隔。仿真和实物的 Z 轴角速度均值分别为 0.2883 和 0.3067 °/s，标准差分别为 0.01935 和 0.01881 °/s。Z 轴加速度标准差分别为 0.001171 和 0.000691 g，开发集中的静置波动较大。三轴均值的详细差值见 [results.json](results.json)。平移加速度由车体世界速度的变化量计算，目前的手持记录没有带独立加速度参考的底盘平移实验。

## 实车接口

仿真 `ImuSensor.sample(car, now, dt)` 与实车解码 `sample_from_raw(row, settings, available_time, mount_rpy_deg)` 返回同一种只读 `ImuSample`。实车入口接受 `csv.DictReader` 的一行记录和对应 `settings.json` 字典，将芯片计数转换为 SI 单位。采样时间来自 `t_sample_us`，提供的到达时间应使用同一时钟，单位秒。日志缺省到达时间取采样时刻。

`gyro_rad_s` 和 `accel_m_s2` 按传感器 X/Y/Z 顺序返回，后者包含静止时向上的 1 g 比力。`yaw_rate` 是原始陀螺仪在车体向上方向的投影，保留零偏，可验证控制器的启动校零。车体坐标取 X 向前、Y 向左、Z 向上。Ideal 保留安装方向和真运动，直接输出连续比力与角速度，延迟为零。Nominal 和 Stress 还模拟逐轴增益、偏置和 ADC 量化，按配置量程及有符号 16 位计数上下限截断。
