从仓库根目录复核本次原生窗口运行：

```powershell
$env:SDL_VIDEODRIVER = 'windows'
py -3.12 -m unittest discover -s simulator -v
```

| 专项 | 核验内容 |
| --- | --- |
| 碰撞 | 车推棋持续 1000 步，检查棋子移动、围挡约束和堵转后的里程计偏差。两棋相撞，检查动量传递与地面衰减 |
| 雷达 | 91 束覆盖 ±135°；正前方依次放置棋子、对车和围挡，改变扫描高度，检验到各目标的距离及超高无回波 |
| 窗口 | 运行正式入口的事件循环，创建 1180×680 窗口，读取场地像素，实际调用 SDL 翻帧后发送退出事件。驱动回报 windows |
| 车辆与导航 | 差速转向、反向编码器计数、整轮里程、导航到达及转向指令 |
| 场地与计分 | 20 个种子检验数量、分值、边界、互不重叠和布局复现。另测压线、推出、扣分、终场等待静止和金球判胜 |
| 整场时序 | 推进 14,400 个常规赛物理步及 7,200 个加赛物理步，验证重新布棋和无进球时轻车胜。另测同质量重赛及卡滞复位保留时钟与棋位 |
| 离线分析 | 写入并读取 JSONL，以已知 3 mm、4 mm 双轴偏差验证两车的 5 mm 平面 RMSE |

Pygame 导入时报告第三方 pkg_resources 弃用提示。上述数字来自软件仿真，车辆参数尚待实车标定。
