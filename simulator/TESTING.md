# 测试记录

## 顶墙打滑后的雷达跟踪

全局 Python 3.12、Windows 原生 SDL，55 项通过，零跳过。车辆从 (2600,500) mm 向右墙行驶，0.8 PWM 持续 4 秒，随后 −0.6 PWM 倒车 2 秒再停车 1 秒。在顶墙和退回开阔处两个检查点，原始里程计 x 误差均超过 1200 mm，雷达位姿有效，平面位置误差均小于 5 mm。另用空扫描模拟短时失明，叠加 1300 mm 的里程计误差，恢复回波后连续两帧确认定位。

## V2.1.1 审查修复

V2.1 发布时有 45 项，随后增加 3 项围挡定位测试，审查基线共 48 项。本次增加 5 项。全局 Python 3.12、Windows 原生 SDL 全量执行 53 项，零跳过。

- 在无障碍场景分别给定 120、180、300、400 及 −180 mm/s 轮速阶跃，双轮峰值不超过目标绝对值的 105%。从第 2 秒到第 3 秒，按 100 ms 编码器计数差测速，误差保持在 ±5% 内。默认 180 mm/s 指令时轮缘速度峰值为 180.96 mm/s。
- 纵向接触隐式更新计入车轮和车体的两项柔度，并用上一拍接触点的速度变化估计外力影响。高刚度近堵转、低附着、能量及步长收敛用例继续通过。当前无棋制动/滑行距离为 21.88/668.78 mm；100/200/400 Hz 对照终点 x 为 322.041/321.979/321.946 mm。历史版本的记录保留在下方。
- 数值回归锁定手册推棋表全部九个值、两项停车距离及三个步长终点，容差 0.01（对应 mm 或 mm/s）。另验证中心附近三处镜像拒绝及手动转向幅度映射。
- [房间采集复核](../lidar_analysis/README.md)可独立重跑。75 帧均未通过比赛地图匹配。

## V2.1 · 2026-11-27

系统 Python 3.12.10、Pymunk 7.1.0、SDL Windows 原生驱动。运行下方全量测试命令，45 项通过，零跳过，用时 10.072 秒。原有 33 项全部保留，新增 12 项测试位于 [test_dynamics.py](test_dynamics.py)。

| 实验 | 条件和结果 |
| --- | --- |
| 恒力、恒扭矩和质量 | 0.6、1.2、2.4 kg 的 260×220 mm 车体，关闭地面牵引。质心施加恒力 2 N 及恒扭矩 0.02 N·m，持续 0.5 s。速度和角速度分别与 Ft/m、τt/I 一致至小数点后 8 位；200 Hz 下位移相对误差约 1%。 |
| 重心及惯量 | 偏心 1 kg 底盘加 0.2 kg 平推板，总重 1.2 kg，合成重心为 (10,5) mm，转动惯量通过平行轴公式比对。检验质量采用装板总重。 |
| 电机和转向 | 验证空载转速、启动限流、反转与死区。右电枢电阻由 4 Ω 增至 8 Ω 后，等 PWM 行驶产生右偏。额定点换算满足电压和扭矩方程。 |
| 堵转和滑移 | 车辆顶住矩形障碍。在普通附着力下，车体近静止、轮轴仍约 6.05 rad/s；高附着高刚度工况轮轴约 0.05 rad/s，电流约 1.01 A，接近该占空比锁轴电流。另用斜向速度扰动验证纵向力与侧向力的合力上限。 |
| 滑行与制动 | 两车轮同给 0.55 PWM 持续 1 s，随后零 PWM 持续 2 s。默认 1.2 kg 无棋场景，制动模式前移 19.92 mm，滑行模式前移 668.51 mm；逐步核查车体与车轮总动能未增加。另从相同的 400 mm/s 初速检验三种质量的制动距离。 |
| 步长收敛 | 同给 0.55 PWM 持续 0.3 s，再制动 0.2 s。物理和电机频率同步取 100/200/400 Hz，最终 x 分别为 322.309、322.120、322.021 mm，连续两次差值从 0.188 mm 降至 0.099 mm。 |
| 棋子接触与负载 | 无地面摩擦的两棋正碰验证总线动量，有摩擦时验证衰减。检查同一推棋输入下三种车重的棋子位移、转向响应、制动距离及低附着时的牵引力。各工况数据见手册。 |
| GUI 与回放 | 实际创建七页 Tk 工作台，切换地面、修改乙车质量，校验功能键绑定。Windows 原生仿真窗口接受手动零 PWM 接管并完成 80 步录制回放，含轮系遥测的终态一致。另用两个独立 Python 进程对照默认 800 步实验，终态一致；离线分析读取 48 帧。 |

全部为软件实验。实车的电机特性和地面附着力仍待标定。
