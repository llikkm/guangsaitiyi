# V2.1 车辆动力学工作台说明书

## 第一次驾驶

在仓库根目录运行：

```powershell
py -3.12 simulator/studio.py
```

选择“甲车”，将质量设为 1.2 kg，零 PWM 模式选 `brake`。按 **F5** 打开驾驶窗口，按住 ↑ 加速，松开后观察 Body 速度和左右轮电流。按 **F3** 减慢仿真，便于观察刹车瞬间。关闭驾驶窗口后，参数工作台仍然可用。把质量改成 2.4 kg 再运行一次即可做对照。正式比较使用 F6 和相同算法，消除手动按键时长的差异。

依赖沿用系统 Python 3.12、Pymunk 和 Pygame。工作台使用标准库 Tkinter。离线安装命令见[运行说明](README.md)。

## 工作台操作

七个页签分别管理实验场地、甲乙两车和四个电机。参数在下一次启动实验时生效，已打开的实验使用其启动快照。可用 Tab 移动焦点，Ctrl+PageUp/PageDown 切换页签，页内滚动条查看下方参数。

| 快捷键 | 按钮 | 用法 |
| --- | --- | --- |
| F4 | 切换地面 | 在低附着、粗糙、普通预设间循环。同步设置两车的轮胎附着、滚阻和全场棋子滑动摩擦，之后可逐项修改 |
| F5 | 手动驾驶 | 默认甲车由方向键驾驶，乙车运行其配置的控制器 |
| F6 | 算法实验 | 两车分别加载自己的控制器，按相同物理规则运行 |
| F7 | 保存方案 | 将当前参数、参数来源、场景和控制器路径保存为 JSON |
| F8 | 载入方案 | 载入已有工作台 JSON 或 V2.1 TOML。跨电脑使用时检查控制器路径 |
| F9 | 回放日志 | 选择实验目录中的 run.jsonl，用记录的逐步输入重演 |

驾驶窗口中每个按钮都标有对应键：

| 按钮或手势 | 效果 |
| --- | --- |
| Pause [Space] | 暂停或恢复物理时钟 |
| Team [Tab] | 选择甲车或乙车。切走的手动车收到零 PWM |
| Manual [F2] | 在本车的算法与手动驾驶间切换，回放期间按日志驾驶 |
| ↑ / ↓，← / → | 手动前进、倒车和差速转向。松开后输出零 PWM |
| 单击场地 | 在手动模式下设定目标；导航使用估计位姿，轮速目标经 PID 产生 PWM。方向键可接管 |
| Stop [End] | 当前车转为手动零 PWM，取消目标。仍按住的方向键需松开才重新驱动 |
| Slower [F3] / Faster [F4] | 仿真倍率减半或加倍，运行中可降到 1/60。要直接选 0.1 倍，可在工作台“仿真倍率”填 0.1 |
| FPS [F5] | 循环切换 15、30、60、120 FPS。物理频率单独配置 |
| Close [Esc] | 结束本次实验，写入日志结束记录并返回工作台 |

F5/F6 在工作台启动的每次实验均使用独立目录 `simulator/runs/日期-时间/`，其中 `profile.json` 为当次方案，`run.jsonl` 为输入及遥测。运行达到配置的时长后自动结束。来源下拉框用于标记假设、理论、厂商标称或实测值。更改来源标签只改变记录，不改变物理公式。

## 车体、重心与推板

车体系中 x 向前、y 向左。长宽高和重心偏移填 mm，质量填 kg。轮距是两轮接地点的中心距；轮径用于轮缘线速度和编码器里程换算。默认轮距 145 mm、轮径 65 mm、每轮 1320 计数均为暂定值。车体和附件须满足比赛尺寸约束，装板总重须小于 2.5 kg。

“底盘含载荷质量”计入电池、计算板等已装部件。“推板附加质量”单独计入。例如整车称重 1.20 kg，其中推板 0.08 kg，填底盘 1.12、推板 0.08。没有单独称板时可填底盘 1.20、附加质量 0。质量同时进入碰撞、牵引力上限和加赛检录质量。

底盘重心默认居中。惯量填 0 时使用矩形近似 `m(L²+W²)/12`；手动值为**底盘绕自身重心竖直轴**的 kg·m²。重心偏移时仍使用此中心惯量近似，实测到惯量后可直接替换。推板各段按长度分配质量，按细杆计算中心惯量，再用平行轴定理合并到底盘和推板的共同重心。平车头的附加质量沿前缘横向分布。电池或雷达换位置时，应相应更新底盘质量、重心和已知惯量。

推板选 `flat`、`u` 或 `custom`。U 形可改前伸和开口，自定义折线例如 `[[60,105],[0,85],[0,-85],[60,-105]]`。点以车头前缘中点为原点，单位 mm。甲乙两车可装不同结构。检测到外形超限或场景重叠时，先缩小推板或移动初始位置。

## 电机参数怎么填

先选车辆电池电压，再到对应车的左右电机页。两边参数可以独立设置。缺乏器件资料时保留“假设”标签。默认 7.4 V、4 Ω 和 20:1 减速比用于模型试跑。

| 参数 | 物理含义 |
| --- | --- |
| spec_mode = constants | 直接使用 Ke 和 Kt。Ke 单位 V·s/rad，Kt 单位 N·m/A，两者都指减速前电机轴 |
| spec_mode = rated | 填同一额定工作点的端电压、电流、轴转速 rpm、轴扭矩 N·m 及绕组电阻。按 Kt≈τ/I 和 Ke≈(V−IR)/ω 换算。额定转速填电机轴转速，使用减速箱输出数据前应折算 |
| 电池端电压、死区 | 电机使用平均电压 u×V。占空比绝对值处于死区内时按零指令处理 |
| 电枢电阻、限流 | 电流取 (uV−Ke·ω电机)/R，随后限制在 ±限流值内 |
| 堵转扭矩上限 | 电机轴扭矩取 Kt×电流，并受该上限约束。供电或驱动限流可使实际堵转扭矩更低 |
| 减速比、效率 | 电机转速等于轮速乘减速比，轴扭矩经减速比和效率换算到轮端 |
| 轮侧等效惯量 | 单轮 kg·m²，包含车轮及折算到轮侧的转子和传动惯量。增大后车轮对扭矩变化反应较慢 |
| brake / coast | 零 PWM 时，brake 按端电压为零形成反电动势制动电流；coast 断开电枢，电流为零，滚阻及接触力仍起作用 |

模型使用平均电压，不解析 PWM 载波周期。电感、电池压降、绕组温升和减速箱间隙尚未建模。理想空载电机转速由 V/Ke 决定，实际落地速度还受负载、效率和滚阻影响。

## 轮胎、地面与编码器

每个物理步独立更新两轮角速度和角位移。轮胎纵向作用力取决于轮缘速度 rω 和接触点纵向速度的差，侧向力阻碍侧滑。轮胎受到的反扭矩会降低轮速。纵横向力的合力受 μN 限制。默认采用两驱动轮承担总重的平面近似，根据左右重心偏移分配法向载荷；前后偏移改变力臂。尚未模拟脚轮承重、动态载荷转移和抬轮。

“纵向滑移刚度”和“侧向滑移刚度”单位为 N·s/m。较大的值使轮胎在小滑移时更快建立力；在极硬接触下应同时检查物理步长收敛。“滚动阻力系数”决定滚阻矩 μ滚×N×r。棋子地面摩擦单独施加在棋子上；“实体表面接触摩擦”用于 Pymunk 中车体、棋子、挡板之间的实体碰撞。

| 地面预设 | 轮胎附着 μ | 棋子滑动 μ | 滚阻系数 |
| --- | ---: | ---: | ---: |
| 普通 | 0.72 | 0.105 | 0.012 |
| 低附着 | 0.08 | 0.05 | 0.008 |
| 粗糙 | 0.90 | 0.35 | 0.025 |

编码器计数取 `round(轮角位移 / 2π × 每轮计数)`。观察窗口的 Wheel rad/s、Slip m/s 和 Body mm/s 可区分轮转与车动。日志中每车 `wheels` 按左、右排列：omega 为 rad/s，angle 为累计 rad，motor_rpm 为电机轴 rpm，current 为 A，shaft_nm 和 torque 分别为轴扭矩与轮端有效驱动扭矩（N·m），longitudinal_n 和 lateral_n 为轮胎力（N）。`latched_pwm` 给出电机任务最近锁存的占空比，`body_velocity_mm_s` 和 `angular_velocity_rad_s` 分别记录车体线速度及角速度。日志保留采样时的轮系状态和每个物理步的控制输入。

电机和轮胎计算使用 SI，碰撞引擎使用 kg、mm、s。统一换算为 1 N = 1000 kg·mm/s²，1 kg·m² = 1,000,000 kg·mm²。解析测试覆盖两项换算。

## 如何做对照实验

1. **只换车重。** 复制同一方案，固定种子和两侧 PWM，保持推板、棋子及地面相同。对比起步、转弯和停车距离。要单独测制动，先给各车相同初速；标准实验使用 400 mm/s。
2. **区分负载与打滑。** 设置 `scene` 为 `{"pieces":[],"obstacles":[[500,200,60,300,150]]}`，从默认发车区向前开。观察车速接近零时，轮速是否仍高、电流是否上升。降低轮胎附着后重新运行，用编码器行程对照真实位移。
3. **实车标定。** 分别称车、推板和棋子；测整车轮径与轮距，核对减速后的每轮计数。记录空载转速和不同负载下的电流，用同一批次地面比较零 PWM 制动与滑行距离。通过记录的实验批次标记实测来源，再评估轮速 PID。

默认模型的一次推棋实验使用平车头，棋心初始在 (400,200) mm，车中心在 (200,200) mm，初速为零；两轮给 0.55 PWM 持续 1 秒，再给零 PWM 制动。200 Hz 仿真结果如下。

| 底盘质量 | 1 秒时车速 | 1 秒时棋子前移 | 随后制动距离 |
| ---: | ---: | ---: | ---: |
| 0.6 kg | 410.39 mm/s | 337.02 mm | 15.22 mm |
| 1.2 kg | 408.64 mm/s | 330.21 mm | 19.86 mm |
| 2.4 kg | 405.08 mm/s | 311.27 mm | 33.74 mm |

这组输入下，重车起步较慢。进入附着限制时，总重同时提高 μN，推棋结果要结合电机扭矩和地面条件判断。以上参数和数值来自仿真。实车加速时间、制动距离与推棋能力待实物标定。

## 命令行和测试

```powershell
py -3.12 simulator/sil.py --manual --seconds 120
py -3.12 simulator/sil.py --config simulator/v21.toml --seconds 4 --record simulator/runs/v21-demo.jsonl
py -3.12 simulator/sil.py --gui --replay simulator/runs/v21-demo.jsonl --speed 0.1
py -3.12 simulator/experiment.py simulator/runs/v21-demo.jsonl
py -3.12 -m unittest discover -s simulator -v
```

给新实验选新的日志文件名。脚本批量试验可用 `--profile 自己保存的方案.json` 指定物理参数，命令行用 `--seed`、`--seconds`、`--speed` 指定本次调度。TOML 用 `[team_a.vehicle]` 修改车体，`[team_a.left]`、`[team_a.right]` 修改电机；乙车同理。共享理化参数默认在 `[dynamics.assumed]` 和 `[dynamics.motor_assumed]`；也可用 nominal 或 measured 及 motor_nominal、motor_measured 记录来源。工作台方案直接保存每项来源。

V2.0 对照实验显式指定 `--config simulator/v2.toml`；回放旧日志时按所存方案选择物理路径。原 V1.1 手动实验仍可通过 `simulator/main.py` 启动。各标准实验的通过条件和执行记录见[测试记录](TESTING.md)。
