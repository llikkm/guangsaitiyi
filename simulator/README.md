# 光电象棋二维仿真

在同一块场地上驾驶两辆差速车、推动棋子，观察碰撞后的真实轨迹和传感器估计。坐标原点在场地左下角，向右为 +x，向上为 +y，航向角从 +x 逆时针计。长度用 mm，时间用 s，质量用 kg，日志角度用 rad。

## 工作台与算法实验

V2.2.3 在「传感器」页选择陀螺量程即可联动灵敏度。测试急转定位时选 Nominal 或 Stress、dense、密扫逐束运动补偿 odometry。查看[三档转速对照](TESTING.md)。

V2.2.2 侧栏的 `Estimated xy` 和 `Estimated yaw` 显示原始里程计。顶墙对照实验及与 STM32 算法的差异见[测试记录](TESTING.md)。

V2.2.1 的 `Nav xy mm` 和点击导航共用雷达校正后的估计。首次获得有效雷达定位前使用起点和里程计；两次有效扫描之间由编码器和陀螺更新。

当前工作台为 V2.2。从根目录运行 `py -3.12 simulator/studio.py`，在「传感器」选择 Ideal、Nominal 或 Stress，用 F5 手动驾驶、F6 运行算法。快速模式适合日常调车，高密度模式可研究扫描运动畸变。[V2.2 传感器手册](V2.2手册.md) · [车辆动力学与操作](V2.1手册.md)

在仓库根目录运行以下命令。默认示例中甲车先直行，再原地旋转并停车，乙车留在发车区。

```powershell
py -3.12 simulator/sil.py --gui --seconds 4
py -3.12 simulator/sil.py --seconds 4 --record simulator/runs/demo-v2.jsonl
py -3.12 simulator/sil.py --gui --replay simulator/runs/demo-v2.jsonl --speed 0.1
py -3.12 simulator/experiment.py simulator/runs/demo-v2.jsonl
```

无窗口运行按固定物理步连续计算，用 `--seconds` 指定仿真时长。窗口模式支持 `--speed 4` 加速，空格暂停，上下键调速，Tab 切换车辆。关闭窗口会结束本次运行。录制时使用新的文件名。

修改 [v2.toml](v2.toml) 的 `team_a.controller` 和 `team_b.controller`，即可用相同场景比较两套算法。自定义配置用 `--config 路径` 指定。传感器单位、调度顺序和场景格式见[控制器接口说明](CONTROLLERS.md)。

## V1.1 手动驾驶与依赖安装

在 Windows PowerShell 中从仓库根目录运行。当前离线安装包适配 Windows x64 和 CPython 3.12。

```powershell
cd simulator
py -3.12 -m pip install --no-index --find-links wheels -r requirements.txt
py -3.12 main.py --seed 42
```

`wheels/` 是本机已下载的安装包目录。该目录由 Git 忽略，新克隆需自行准备匹配平台的 wheel 才能离线安装。新克隆在联网环境可直接运行 `py -3.12 -m pip install -r requirements.txt`。用 `--config 文件路径` 加载另一份完整 TOML 配置。

| 操作 | 效果 |
| --- | --- |
| P | 开始、暂停或恢复比赛。暂停期间停表 |
| 方向键 | 驾驶所选车辆。左右键控制转向，松键减速 |
| 单击场地 | 使用估计位姿导航到该坐标。方向键接管导航 |
| Tab | 切换甲车和乙车 |
| 空格 | 取消导航并制动，比赛继续计时 |
| J | 裁判处理双车卡滞，停表，两车回发车区，保留棋位。按 P 恢复 |
| 减号 | 给当前队记一次 5 分扣罚。首次警告由操作者掌握 |
| S | 将截至当前的实验写入工作目录下的 `runs/` |
| R | 按相同种子重新开局并清空当前记录，需要保留的实验请先按 S |
| Esc | 关闭窗口 |

## V1.1 推棋和慢动作

试用顺序：开局点 **Bumper** 选挡板，点 **Play/Pause** 发车，用方向键驾驶。点 **Speed** 切换实时速度，选到 **1/10x** 时，现实 1 秒推进 0.1 秒仿真。用 **Replay** 从头查看本局，回放时也能随时调速、暂停和切换所观察的车。想保留这一局可点 **Save**；**Reset** 开始新记录。

| 控件 | 快捷键 | 选项 |
| --- | --- | --- |
| Speed | T | 原速、1/2、1/5、1/10、1/20、1/30、1/60 |
| FPS | F | 窗口帧率上限 15、30、60 或 120，可在运行中切换 |
| Bumper | B | 开局前循环选择平车头、U 形或自定义折线，两车采用同一方案 |
| Replay | V | 从本次实验开头回放。再点一次从头看，Reset 返回驾驶 |

默认物理步长为 1/120 秒。在 1/60 倍速下，每过 1 秒现实时间推进 2 个物理步。窗口可以同时按 60 FPS 刷新，参数在物理步之间保持原值。右侧 Body speed 是车体移动速度，可和 Wheels 的轮缘速度对照。中文输入法开启时可直接点窗口按钮，也支持通过物理键位触发字母快捷键。

**调整挡板**　编辑配置中 `bumper`（`flat`、`u`、`custom`）。U 形挡板用 `bumper_depth` 和 `bumper_width` 调整前伸量和两侧中心线间距。自定义形状由 `custom_outline` 的点依次连接，相邻两点间有实体碰撞。以车头前缘中点为原点，第一列沿车头向前，第二列向左，单位 mm。例如 `[[60,105],[0,85],[0,-85],[60,-105]]` 构成一个向前张开的口。板厚为 `bumper_radius` 的两倍，板高为 `bumper_height`。挡板按刚性附件建模，使用配置中的整车质量。

**调整地面**　`piece_mu` 控制棋子脱离车头后的滑动摩擦，数值越大，停止距离越短。在默认步长下以 200 mm/s 释放棋子，默认值 0.105 的仿真滑距为 18.59 mm；改为 0.35 时为 4.99 mm。可拍摄真实棋子脱离推板的过程，测出初速 v 和滑距 d，用 μ ≈ v²/(2gd) 估算，再在相同初速下比较仿真滑距。使用 mm 时 g 取 9810 mm/s²。当前摩擦参数来自假设。

**打开保存的回放**　在 simulator 目录下运行：

```powershell
py -3.12 main.py --replay (Get-ChildItem runs/*.jsonl | Sort-Object LastWriteTime -Descending | Select-Object -First 1).FullName --fps 60
```

点 Play/Pause 开始。V1.1 的 JSONL 首行含 `software`、格式号、配置及种子。输入记录以从零开始的 `step` 标记物理步，每个 `drive` 包含甲乙两车的左右轮指令（mm/s）；同一步的裁判操作按文件顺序执行。暂停期间无物理步，回放跳过等待的现实时间。遥测行沿用原有格式，离线分析同时支持 V1 和 V1.1 日志。V1 旧日志只保存采样时的指令。

## 赛题核对

依据仓库内第一轮通知 PDF 第 4 页图 1、第 5 至 6 页的比赛流程和第 7 至 8 页附件。场内净尺寸 3000×2000，围挡高 300。两侧球门区均为 400×600，中央布棋区为 600×600。甲车从左下、乙车从右上的 300×300 发车区起步。球门与地面齐平。默认发车区距相邻围挡 50 mm，图中未标此间距，值可调整。

黑底棋子直径 67、厚 17，甲方红字、乙方白字，各 16 枚。界面用字母区分棋种。G 帅/将 10 分，R 车 5 分，H 马和 C 炮各 3 分，A 仕/士和 E 相/象各 2 分，P 兵/卒 1 分。每方总分值 45。布棋从中央区域随机抽取单元格，再在格内随机偏移，确保全部棋子完整落入区域且互不重叠。

棋子完整进入本方球门且未压线时计入本方比分，被推出后扣回。常规赛满 120 秒停止驱动，待棋子滑动结束后结算。平局时复位两车，重新布棋，独立进行 60 秒金球加赛。同一物理步内双方都进球，或加赛无进球，按检录质量判轻车胜。等重则再赛。全部棋子在同一平面上滑动。手动驾驶用于调试车辆，正式比赛要求自主运行。

## 参数和模块

`config.toml` 的 `theoretical` 保存规则或理论值，`assumed` 保存假设值，`nominal` 保存厂商标称值，`measured` 保存实测值。同名项按此顺序覆盖。默认轮距 145 mm、轮径 65 mm、每轮 1320 计数均为暂定值。两车质量默认各 1.2 kg。接触摩擦、棋子地面摩擦和驱动力均可调。车体长宽高上限各 300 mm，检录质量须小于 2.5 kg。

| 模块 | 职责 |
| --- | --- |
| rules.py / match.py | 读取配置、布棋、计分和比赛时钟 |
| physics.py / vehicle.py | Pymunk 场景、固定步长推进、轮力和接触 |
| sensors.py | 按物体高度过滤激光射线，使用编码器增量和陀螺角速度更新估计位姿 |
| control.py | 将目标坐标转为左右轮速度 |
| main.py | Pygame 窗口、操作、实时遥测和轨迹 |
| experiment.py | 保存实验和离线计算误差 |

默认物理频率 120 Hz。雷达在 55 mm 高度以 12 Hz 扫描，270° 视场含两端共 91 束，量程 4000 mm。默认可见围挡和对车，射线越过棋子。返回距离单位为 mm，无回波记为 null。导航读取 `World.estimates`；`World.cars[i].body` 保留独立物理真值，可用于定位评测。

## 实验与测试

按 S 后，窗口底部显示 JSONL 文件名。首行含随机种子和生效配置，后续每行记录物理步、比赛时钟、比分、两车和棋子状态。两车各自包含真值、估计、编码器、角速度、轮速指令及雷达数据。扫描附带采集时刻和对应真值位姿，方便离线对齐。用相同配置和种子可复现初始布局，动态重现还需要相同的逐步控制输入。

```powershell
py -3.12 experiment.py (Get-ChildItem runs/*.jsonl | Sort-Object LastWriteTime -Descending | Select-Object -First 1).FullName
py -3.12 -m unittest discover -s . -v
```

分析结果包含两车平面位置误差的均方根，单位为 mm。窗口测试默认打开窗口并自动退出；无桌面的测试机可显式设置 `SDL_VIDEODRIVER=dummy`。本机原生窗口和物理测试的执行结果见 [测试记录](TESTING.md)。

V2.1 驾驶窗口显示雷达估计的车中心和四面墙距。接口、实车接入与验证见[雷达定位 README](localization/README.md)。
