# V2.2 传感器实验

默认 Ideal / fast 用于检查几何和单位。评估转弯时的定位可靠性，选 Nominal 或 Stress / dense。「密扫逐束运动补偿」选 odometry 时，每束回波按采集时刻的编码器和陀螺里程计换算到末束坐标系。选 off 可做对照。两种设置均保留原始扫描及 Estimated 位姿。陀螺削顶后，补偿所用的转角也会偏小。

工作台选择量程时自动填写 LSM6DS3TR-C 标称灵敏度；TOML 只填标准量程也会自动配对。默认 ±250 °/s 对应仓库实机采集配置。尝试更大量程的仿真实验时，实车需要另行设置寄存器及解码系数。[芯片数据手册](https://www.st.com/resource/en/datasheet/lsm6ds3tr-c.pdf)

| 量程 ±°/s | 灵敏度 (°/s)/count |
| ---: | ---: |
| 125 | 0.004375 |
| 250 | 0.00875 |
| 500 | 0.0175 |
| 1000 | 0.035 |
| 2000 | 0.070 |

V2.2.2 窗口同时显示两组位姿。观察编码器打滑误差时看 `Estimated xy/yaw`，对应 JSONL 的 `estimate`。点击导航时看 `Nav xy/yaw`，对应 `navigation_pose`。`Wheel rad/s` 是左右轮的模拟实际转速，`Body` 是车身速度（mm/s）。

V2.2.1 手动驾驶时可点击场地设置目标。`Nav xy mm` 是导航使用的当前位置。雷达每次成功匹配墙面后校正位置及航向，再用该次采集以来的里程计变化补到当前时刻。持续缺少有效扫描时，空转仍会带来误差。录像中对照 `navigation_pose` 和 `estimate` 即可观察校正效果。

从仓库根目录运行 `py -3.12 simulator/studio.py`。在「传感器」页选误差模式和雷达扫描方式。按 F5 手动驾驶，或按 F6 让两队算法驾驶。F7 保存当前配置，F9 回放一场已记录的实验。物理引擎和驾驶操作沿用 [V2.1 手册](V2.1手册.md)。

| 想观察什么 | 工作台设置 | 实验中看什么 |
| --- | --- | --- |
| 检查算法几何和单位 | Ideal、fast | 每帧 91 束同时采集。静止时陀螺仪角速度为零 |
| 转弯时一面直墙如何变形 | Ideal、dense | 原地转弯，比较点云与围挡。每帧 3375 束，首末束间隔约 74.5 ms |
| 输入实测水平的传感器误差 | Nominal、dense | 停车时观察航向随陀螺仪零偏漂移，对照雷达独立估计 |
| 检查短时失锁和迟到的数据 | Stress、dense | 雷达固定区域被遮挡，噪声和交付延迟增加，可能整帧丢失。算法按样本时间判断新鲜度 |

快速与密集扫描均可调频率、视场和范围。密集模式的束间隔可调。工作台中的 IMU 和编码器采样频率位于「实验与场地」。默认物理步长 5 ms、IMU 104 Hz、编码器 100 Hz。IMU 与编码器在到期后的物理步取样，故单次间隔会受物理步长影响。雷达按束时钟插值。实测波动和采集设置来自这台设备，传输延迟等尚无同步参考的参数使用可调假设。各轴数据和来源详见 [IMU 标定](../imu_analysis/README.md)，雷达参数依据详见 [PAVO 模型](PAVO.md)。

## 控制器怎样读取

在已有控制器的 `update(robot, dt)` 中可直接读取只读样本。程序可按 `time` 去重，也可使用 `robot.time - packet.time` 计算数据年龄。控制器读取的是最近一次已经交付的样本。启动和复位后，首个有效样本到达前字段为 None。

| 字段 | 含义和单位 |
| --- | --- |
| `robot.lidar_sample` | `beams` 每项为雷达本地角 rad、距离 mm 或 None。`times` 是各束采集时间 s，`time` 为末束时刻，`available_time` 为传输完成时刻 |
| `robot.imu_sample` | `gyro_rad_s`、`accel_m_s2` 为传感器坐标系 XYZ 三元组，静置时比力模长约 9.81 m/s²。`yaw_rate` 为陀螺读数在车体竖直轴的投影 |
| `robot.encoder_sample` | `tim3` 为左轮、`tim8` 为右轮，范围 0 至 65535。前进时原始右轮计数递减。两次采样之间每轮位移须小于 32768 计数才能唯一恢复方向 |
| `robot.wall_fix` | 雷达定位解使用末束时刻的里程计预测。原有 `estimated_pose` 保留编码器和陀螺推算的结果 |

轮子打滑时，编码器继续按照轮轴转角计数。原接口 `read_encoders()` 返回统一前进方向、解开回绕后的累计计数。`read_imu()` 仍返回标量航向角速度。`read_lidar()` 返回本地束角和距离。帧内运动畸变保留在雷达读数中，定位器可用于观察它对拟合的影响。

## 实机接入与记录

实机驱动应将各传感器时间换到同一个单调时钟，再组装以下数据。仿真真值只出现在评估日志和场地视图。

- 雷达驱动把原始包角度（度）、距离（米）、各束时间和接收完成时间交给 `ScanSample.from_pavo()`。传感器相对车体的位置和方向交给 `RectangleLocator`。驱动负责组帧和时钟同步。
- ESP32 实测日志可用 `sample_from_raw()` 转为 `ImuSample`。STM32 上的 `ChassisImu_GetLatest()` 返回六轴原始快照与读取完成的系统 tick；这个 tick 表示 MCU 读完数据的时间。接入时应明确采样时刻的估算方式。[底盘驱动说明](../AMR_NEW_CodingDay4/README-CodingDay4.md)
- 对同一次锁存的两个计数器构造 `EncoderSample(time, available_time, tim3, tim8)`。后一帧调用 `travel_delta(前一帧)` 得到双轮有符号增量。

运行一次无窗口实验可用 `py -3.12 simulator/sil.py --seconds 4`。使用 `--record 新文件.jsonl` 保存参数、种子和实际控制输入。扫描更新时的遥测包含各束时间、最近的六轴样本和原始编码器寄存器。用 `--replay 文件.jsonl` 重演。`--config simulator/v21.toml` 选择旧版动力学及传感器对照；已有旧版本录像按原配置回放。

## 附录　V2.2 已实现的系统功能

本清单覆盖截至 **V2.2.3** 可从工作台、驾驶窗口或命令行使用的功能。

### 比赛、车辆与驾驶

| 功能 | 可以做什么 |
| --- | --- |
| 场地与布棋 | 在 3000 × 2000 mm 场地上模拟双车比赛。红白双方各有 16 枚直径 67 mm 的棋子，可在中央布棋区随机无重叠摆放，也可指定车辆初始位姿、棋子位置和障碍物。 |
| 计分与计时 | 按棋种分值实时计分，棋子完整进入本方球门得分，移出后扣回。常规赛计时 120 秒，结束后待棋子停稳再结算，平局进入 60 秒金球加赛。 |
| 车辆与挡板 | 甲乙两车可分别设置质量、尺寸、重心、转动惯量及左右电机参数。在「甲车」或「乙车」页选择平头、U 形或自定义挡板；选择 `custom` 后，在「自定义折线」中按顺序输入顶点坐标，相邻点之间的板段参与实际碰撞。 |
| 驱动与推棋 | 左右轮 PWM 通过电机、减速机构和轮胎牵引驱动车体。可比较制动与滑行、低附着打滑、顶墙空转和近堵转，也可调整棋子滑动摩擦，观察棋子离开挡板后的滑距。 |
| 手动驾驶与点击导航 | 工作台按 **F5** 进入手动驾驶。方向键控制前后和转向，Steering 滑条连续调节转向幅度。单击场地即可驶向目标点，方向键可接管。驾驶窗口按 **Tab** 切换车辆，**F2** 切换所选车辆的手动接管，**End** 停车。 |
| 实时观察与慢动作 | 窗口绘制双车轨迹和雷达点云，侧栏显示位姿、PWM、编码器计数、车身速度、轮速、电流和打滑量。驾驶窗口按 **空格** 暂停，**F3 / F4** 减速或加速，最低可到 1/60 倍；**F5** 切换显示帧率。 |

### 传感器与定位

| 功能 | 可以读到或比较什么 |
| --- | --- |
| 双轮编码器 | 从两轮各自转过的角度产生计数，可读取模拟 TIM3/TIM8 的 16 位寄存器、处理回绕后的有符号增量和累计计数。顶墙时可对照轮速与车身速度，查看空转如何造成里程误差。 |
| 六轴 IMU | 输出三轴角速度、三轴加速度和用于航向积分的角速度。可调采样率、安装姿态、零偏、噪声及延迟；在工作台选择陀螺量程时自动配对灵敏度。 |
| PAVO 雷达 | 支持 fast 瞬时扫描和 dense 逐束扫描，按扫描高度检测围挡、对车和障碍物。可配置视场、量程、盲区和丢点；控制器可读取每束角度、距离及采集时间，以及整帧的交付时间。 |
| 三种误差模式 | Ideal 用于几何对照，Nominal 引入配置的传感器误差，Stress 可测试更强噪声、额外盲区和数据延迟下的算法表现。 |
| 位姿与墙面定位 | `Estimated xy/yaw` 显示编码器和陀螺推算的原始位姿；`wall_fix` 给出成功匹配时的雷达位姿和四面墙距，失败时给出原因；`Nav xy/yaw` 显示点击导航使用的当前位姿。可用同一时刻的仿真真值计算误差。 |
| 密扫运动补偿 | 根据逐束采集时间、安装位置和里程计，把回波换算到末束时刻后再匹配墙面。在「传感器」页切换 `odometry / off`，可对照同一条转弯轨迹的定位效果，同时保留原始点云。 |

### 控制算法与可复现实验

| 功能 | 使用方式 |
| --- | --- |
| 双车独立控制器 | 为甲乙两车分别指定 Python 控制器，工作台按 **F6** 运行。算法从统一接口读取传感器和估计位姿，可输出左右 PWM、目标轮速或停车指令。目标轮速经闭环控制器转换为 PWM。[控制器接口](CONTROLLERS.md) |
| 独立仿真时钟 | 物理引擎按固定步长推进。电机、轮速控制、传感器和上层算法按各自频率更新。可在窗口中慢放观察，也可无窗口运行同一实验。 |
| 参数与方案管理 | 工作台集中调整两车、四个电机、地面和传感器参数，支持标记参数来源。**F4** 切换地面预设，**F7** 保存方案，**F8** 载入方案。 |
| 记录、回放与分析 | 使用固定种子复现布棋与传感器扰动，将配置、逐步控制输入和带时间戳的遥测保存为 JSONL。工作台按 **F9** 回放；日志可对照车体真值、原始里程计和导航位姿，离线分析工具可计算两车的里程计位置均方根误差。[测试记录与实验结果](TESTING.md) |
