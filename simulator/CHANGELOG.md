# 仿真版本记录

## V2.1.1 · 可靠性审查修复

修正动态电机的轮速前馈和轮胎纵向力的隐式更新；为历史 V2.1 输入日志保留原动力学。新增中心镜像拒绝、连续手动转向幅度、标准实验数值回归及房间雷达样本复核。

## V2.1 · 2026-11-27

- 新增两车独立的质量、尺寸、重心、惯量与带质量推板；轮速控制器驱动平均电压直流电机，经齿轮和轮胎接触施力。
- 新增限流、左右电机差异、制动及滑行、电机额定点换算和滑移遥测。保留 V2.0 物理路径用于回放和对照。
- 新增中文参数工作台，支持方案复用和地面预设，手动驾驶和算法实验使用同一物理路径。操作按钮显示快捷键。
- 新增车辆动力学标准实验及[操作与建模说明书](V2.1手册.md)。

## V2.0 · 2026-11-27

- 新增独立算法运行入口、只读机器人观测和按队加载的 Python 控制器。
- 新增多频率调度、编码器反馈轮速 PID 和 PWM 执行路径，复用原有车辆接触模型。
- 新增可配置实验场景、无窗口加速、原生窗口观察及逐步输入记录回放。手动驾驶仍可从 main.py 启动。

## V1.1 · 2026-11-27

- 棋子使用可调滑动摩擦，在有限距离内停止；车辆继续通过轮力加速和制动。增加车体速度显示。
- 新增平车头、U 形和自定义折线挡板，碰撞与显示共用几何形状。
- 新增可点击的操作按钮，字母快捷键支持物理键位。
- 驾驶中和回放时均可调整速度与窗口帧率。新增逐物理步的控制记录及回放，保留 V1 日志分析支持。

## V1 · 2026-11-26

首次发布二维比赛场地、差速车物理模型、棋子与比赛规则、虚拟雷达、里程计和实验日志。
