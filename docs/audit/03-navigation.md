# 导航算法、风险与复用范围

## 从坐标到电机

| 环节 | 实现与边界 | 源码 |
|---|---|---|
| 指令 | BluetoothRX 逐字节拼行。收到合法目标或 STOP 立即置停止标志，再递增代号并投 Planner。Control 只接收代号与当前一致的路径。格式合法但 IMU 未就绪的命令可能被消耗，需要重发 | C:550–604、688–702，parse_goal、bluetooth_task、control_task |
| 规划 | 读最近一次 pose，计算拐点 (当前 x, 目标 y)，再到 (目标 x, 目标 y)。每段按 ceil(长度 / 0.25 m) 均分，零长段略过，累计最多 64 个路点。无地图、棋盘或障碍输入，无可通行性判断 | C:606–638，add_segment、planner_task |
| 编码器 | 每周期读 TIM3/TIM8 的 16 位计数，差值先按无符号 16 位取模，再解释为 int16。相邻采样真实变化小于 32768 counts 时可跨零处理。按软件方向修正，乘 πD/N 得每轮增量。默认约 0.1547 mm/count，仅是代码假设。当前代码没有把增量除以 dt 计算两轮速度，也没有轮速遥测和目标轮速 | C:14–22、641–674，encoder_delta、control_task |
| IMU | 探测两个地址，设置电源与陀螺量程，前 100 次成功样本求平均偏置。Z 轴读数减偏置，按 131 LSB/(°/s) 比例换成 rad/s。约 1 s 只指稳定 100 Hz 下的采样段，探测、重试和配置延时另计 | C:389–448，imu_register、imu_task |
| 航向 | IMU 就绪且最新成功读数年龄不超过 35 个 tick 时，航向增量使用当前 gyro_rate 乘控制 dt；否则用左右轮增量差除轮距。两者按条件切换，未做加权融合。IMU 不新鲜会请求停车，即使仍可用轮编码器更新位姿 | C:658–686、695–702，control_task；RT:68 |
| 位置 | 本地位姿初值 (0 m, 0 m, π/2 rad)。中点积分：中心位移 (dl+dr)/2，按旧航向加一半航向增量投影到 x/y；最终航向 wrap 到 [−π, π]。+X 为 0，逆时针为正，启动 +Y。位置无外部校正 | C:42、543–547、654–686，wrap、control_task |
| 航向 PID 与转向 | 目标方位用 atan2(dy,dx)，误差 wrap(方位−航向)。P=0.24、I=0.05、D=0.001，积分状态限幅 0.5，微分是环绕误差差值 / dt，计算转向先限 0.34。直行分支再限 0.12。绝对误差达到 0.45 rad 进入原地转，靠预测 150 ms 滑行与 1.75 rad/s 阈值撤 PWM，以 0.40 或首 120 ms 0.58 的占空比转向。误差不大于 0.14 rad 且角速度小于 0.20 rad/s 连续约 80 ms 才退出原地转 | C:706–747，control_task |
| 直行及电机输出 | 前向占空比取 0.36+0.8×距离，限制在 0.42–0.56；路线开始符合条件时最多约 200 ms 用 0.62 助推。左右分别用前向占空比减/加转向，占空比限 ±0.67，经符号映射写双路 CCR。转向用姿态反馈，纵向采用距离调占空比；独立轮速 PID 未实现 | C:70–86、744–765，pwm_pair、motors、control_task |
| 路点与终点 | 推算距离小于 35 mm 时本周期零 PWM，且角速度小于 0.20 rad/s 才推进路点；最后一项设 state=2。无目标航向、速度和停车保持时间检验。该阈值是程序判据，实车误差由独立测量确定 | C:688–769，control_task |

常规外部电脑只下发坐标与 STOP。它既不提供位姿，也不参与每周期控制。没有外部串口也能运行采样、遥测发送和 OLED，但上电默认停车，无本地按钮发目标的业务。若已接收目标，拔掉串口未必触发 UART 错误，车辆可能继续跑。场外设备对原始里程计无依赖，初始棋盘坐标和长期绝对精度仍需另行解决。依据 C:42–51、136–172、570–604、649–769，IRQ:182–188。

## 雷达数据处理

USART3 收到协议描述符后，lidar_task 以 5 B 滑动窗口解析。第一个字节的启动位与其补位需相反，第二字节低位为校验位，角度字段小于 23040（Q6 的 360°上界），距离两个字节为小端 Q2，整数除以 4 得 mm。只统计距离和质量非零的数据。每个 DMA 半块产生有效点数和最近距离，可保留连续块之间的半个节点。序号跳跃清除残留节点。解析前后检查序号和 NDTR，过期半块丢弃。启动位没有用来拼整圈，角度没有保留，距离没有按行驶方向筛选。C:243–343，dma_ready、lidar_task、block_current。

处理后的路径为 Q_Result、Output、UART4 和最新统计，追踪和里程计没有读取 latest_lidar。缺少完整扫描、安装外参、统一时间戳、点云匹配、SLAM、占据地图与避障。距离统计也不能用于判断是否符合竞赛激光等级。C:112–172、305–333、616–769。

## 风险与建议核查

| 优先 | 问题与条件 | 影响及证据 |
|---|---|---|
| P0 | 无通信超时、堵转保护、运动时限或距离/进展监视；PC13 无急停业务，PC 断开或退出只关闭串口 | 链路被拔除或轮子卡住时，继续保留原动作的条件存在。Error_Handler、异常死循环没有关 PWM，硬件定时器可能维持最后比较值。零 PWM 的制动/滑行含义也取决于驱动。C:254–274、649–769；M:312、614–622、676–685；IRQ:88–143、182–188；PC:95–99 |
| P0 | 通信错误未锁止路径代号。UART ISR 置 stop_requested 后，Control 可在接收仍匹配的路径时重新赋值；如果错误计数已被前一周期记为 observed，后续旧规划交付可清除停标志 | 存在故障后未经新命令重新运动的时序。优先在架空台架判定，修复应让故障失效所有待执行命令并要求明确重新启用。C:254–274、586–592、616–636、688–702、762–765 |
| P0 | 路线忽略障碍和场地边界。没有雷达或其他测距停机输入 | 合法坐标可穿墙或撞棋子，固定 L 形不保证在走廊内。C:112–156、616–636、704–765 |
| P1 | 启动手工定向、轮径/轮距/计数和方向为假设，轮滑未检测。IMU 偏置仅在启动估一次且不检查静止 | 直线比例误差随路程增加，持续角速度零偏随时间积累；轮滑及初始偏角带来系统性位置偏差。掉样时改用轮差，恢复时无漂移校正。C:14–22、426–446、658–686；R:7–10、45 |
| P1 | gyro_at 是读完时刻，Control 以最新值积分整个 dt。传感器更新与 Control 异步，二值信号量会合并积压，首次 dt 至少 1 ms。采样状态未提供给上位机 | 可重复积分同一旧速率、漏掉变化，延迟大时一步积分偏差上升。当前 1 kHz 配置下 tick 到秒的系数正确，改 tick 配置时硬编码 0.001、35 和数个毫秒阈值要同步检查。C:348–351、431–443、657–686、723–769；RT:68 |
| P1 | PWM 最小 0.42、没有速度反馈或直行制动曲线。中间路点跨过阈值可反向追点；短路点链在每个路点短暂归零。误差导数与积分在原地转入、出时状态处理不完全一致 | 近点有超调、来回转、短距离打滑或停车后惯性偏差风险。35 mm 无法替代真实终点误差，较小角速度也无法验证末段朝向。C:704–759 |
| P1 | 编码器无输入滤波、跳变限值和断线检查；两电机 PWM 切换以顺序写 CCR 实现 | 噪声或轮子外推可造成错误计数。相邻计数差越过半个计数范围会错号。PWM 预装载更新与两次写入相对时序、驱动换向和制动特性需要示波器确认；不能据代码清零顺序推断硬件有互锁。C:70–86、641–674；M:293–315、350–358、491–499 |
| P1 | 雷达队列有深度 4，却只认最新仍有效半块；在优先任务抢占下出现丢块。描述符只在首次启动匹配，丢块跨描述符时保留旧 header；解析没有强帧级校验。启动失败、重插、DMA/UART 错误无重启与新鲜度标志 | 可冻结最后一帧统计或在错误对齐时短时误收。USART3 未启用独立 NVIC 中断，DMA 有 IRQ，其错误行为需注入验证。C:243–343；MSP:461–498；M:585–594；IRQ:168–229 |
| P1 | 控制任务无到达应答的命令关联；同位置目标产生空路径，标为 0 而非 2。状态 2 对某些仅触发 stop_requested 的错误保持显示。路径超出 64 点时静默截断 | 上位机可能把旧到达当新结果；严重漂移或被推离时可能标记已到达却只走到截断处。新命令在实际刹停前快照 pose，起点也会偏离。C:606–638、688–714、762–766 |
| P2 | UART TX 的互斥或发送错误可被静默丢弃，UART4 RX 重挂的返回值未汇报。半块结果满速约 90 条/s，与 POSE/TIME 共用 UART；高优先级 I2C 阻塞读写也会占用调度时间 | 做两串口同时满载与 I2C 拉低试验，使用外部时间戳查看真实抖动。丢行也可能来自发送超时，不能只看 lost_results。C:90–95、112–171、254–274、373–403、454–464 |
| P2 | I2C 恢复只处理 HAL_BUSY 且 error 带 TIMEOUT，锁内重置外设及延迟，无 SCL 脉冲或硬电源复位。OLED 在同一总线上不断刷新 | 外部设备持续拉低时可能恢复失败并使 IMU 超时停机。停机后虽仍可里程计积分，控制状态不因此恢复。C:373–448、454–537、678–702 |
| P2 | 栈设置较小，业务使用 snprintf、strtof、浮点函数和中断。旧 .su 是逐函数统计，RT 配置未打开溢出检查 | 栈储备需测峰值高水位，并计入库函数及浮点上下文。TIME 的周期和执行耗时分别更新，可能读到相邻两次的数据；DWT 只记录最近样本。C:136–191、202–226、550–567；RT:59–79、119、154–158；Debug/Core/Src/coding_day.su |
| P2 | 监视器读串口异常后直接 return，未再定时刷新；长时间无状态变化不能用 UI 判定车辆已停 | 应使用独立物理断电和串口抓取检验。PC:51–57、80–99 |

## 复用分类

| 类别 | 模块与边界 | 依据 |
|---|---|---|
| 可直接复用 | 同板同接线条件下的 CubeIDE/CMSIS/FreeRTOS、HAL 外设初始化、编码器计数读取框架、DWT 基本测时、OLED 调试和 PC 日志；原样用于基线验证。PWM 低层写寄存器可复用，驱动真值表另测 | M:96–167、228–625；C:70–86、177–226、454–537、641–646；PC:12–105 |
| 需要少量修改 | IMU 及编码器标定，轮增量和时间戳输出、里程计健康标志、UART4 有线收发与失联保护、固定路点追踪作台架基线、兼容雷达的统计与错误重连。I2C 或 UART4 换硬件时重新核对电平和地址 | C:14–26、90–172、243–448、550–769；MSP:93–110、431–503 |
| 需要重新开发 | 可量化的轮速控制及安全状态机、棋盘全局定位与初始/周期校正、雷达整圈与障碍处理、棋格及动态可行路径、终点朝向/对格、棋子识别与赛题对抗决策。雷达解码基础可复用，需提供完整点和时间信息 | C:277–343、606–769 |

赛题复用判断依据是当前源码能支撑的功能。赛题正式指标及现场规则需要用赛事文件核对，当前交付包没有这些文件。
